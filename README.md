# RADIO / TV — потоковый плеер (PWA)

Лёгкий однoэкранный плеер для телефона: **радио и ТВ в одном приложении**.
Сверху — переключатель режима **Radio / TV** (по умолчанию Radio). Радио играет
потоковые m3u/m3u8-станции и показывает «сейчас играет»; ТВ — открытые каналы
(MP4/HLS, включая Rutube live/VOD) на экране 16:9 с OSD и fullscreen. Ставится
как PWA прямо с GitHub Pages — любому, у кого есть ссылка. Без сборки и бэкенда.

Формат — вертикальный, один экран, без переходов в полноэкранные обложки.
Активный пункт подсвечивается и «дышит» эквалайзером. Тёмная и светлая темы,
адаптив под устройство (на десктопе — фиксированная «айфонная» рамка).

## Возможности

- **Два режима**: переключатель **Radio / TV** вверху; по умолчанию Radio.
  Тема и настройки — в нижнем статус-баре.
- **Радио-плейлисты**: собственные m3u (Alt Rock, Каверы, Deep House, Jazz, AI,
  NFS), радиостанции из GTA (III, VC, SA, IV, LCS, VCS — 70 потоков с
  [gtaradio.net](https://gtaradio.net)) + категории каталога
  [radio-browser.info](https://www.radio-browser.info/) (Топ, Россия, Поп, Рок и т.д.).
- **ТВ-плейлисты**: Познавательные (Discovery/NatGeo и др.), Познавательные детям,
  Юмор, Comedy Club (архив Rutube VOD), «Все», ТВ, Новости, Кино, Музыка, Детям,
  Спорт.
- **ТВ-экран 16:9**: OSD (канал, качество, эфир), логотипы каналов, fullscreen и
  «картинка в картинке» (PiP/мини-плеер). HLS — нативно (Safari/iOS) или через
  локальный hls.js (Chrome/Firefox).
- **Rutube**: live и VOD через CORS-прокси (master переписывается, VOD резолвится
  через API).
- **Свой контент** (радио): добавление любого `.m3u`/`.m3u8` по ссылке или
  отдельной станции по прямой ссылке.
- **«Сейчас играет»** (радио): Icecast (`/status-json.xsl`) и SHOUTcast
  (`/7.html`, `/stats?json=1`) через настраиваемый CORS-прокси.
- **Шумы радио при буферизации** (по умолчанию **выключены**): вместо тишины на
  время реального пропадания звука играют помехи из `sample/*.mp3`.
- **Поиск** станций, **избранное**, **недавние**, Media Session, горячие клавиши.
- **PWA**: установка на домашний экран, офлайн-оболочка (потоки — онлайн).

## Развернуть на GitHub Pages (2 минуты)

1. Залей содержимое репозитория на GitHub.
2. `Settings → Pages → Build and deployment → Source: GitHub Actions`
   (либо `Deploy from a branch`, ветка `main`, папка `/root`).
3. Открой `https://<user>.github.io/<repo>/` на телефоне.
4. Установи на домашний экран:
   - **Android/Chrome**: меню ⋮ → «Установить приложение».
   - **iPhone/Safari**: «Поделиться» → «На экран Домой».

Проверенный workflow лежит в `.github/workflows/pages.yml`. Он просто публикует
статику из корня — сборка не нужна.

## Свой прокси для «сейчас играет» (рекомендуется)

Браузер не отдаёт ICY-метаданные из потока и не может читать статус-страницы
радио-серверов напрямую из-за **CORS**. Плеер использует публичные CORS-прокси, но
они бывают перегружены. Надёжнее поднять свой — бесплатно, за пару минут:

1. Заведи аккаунт на [Cloudflare Workers](https://workers.cloudflare.com/).
2. Задеплой `worker/` (`npx wrangler deploy` или копипаст `worker/index.js` в
   онлайн-редактор дашборда).
3. В приложении: **Настройки → CORS-прокси**, добавь строкой:
   ```
   https://radio-proxy.<твой-поддомен>.workers.dev/?url={url}
   ```
   `{url}` — место, куда подставляется адрес статуса.

Прокси можно отключить вовсе (**Настройки → «Показывать трек»**), тогда станции
будут работать, а строка трека просто останется пустой.

## Свои плейлисты

- **По ссылке**: «+» → «Плейлист M3U» → вставь URL файла. Подхватится через
  CORS-прокси.
- **Встроенные**: положи файл в `playlists/*.m3u` и добавь строку в массив
  `BUNDLED` в `js/radio.js` — он попадёт в табы и будет доступен офлайн.

## Запуск локально

Service worker работает только на `localhost` или по HTTPS:

```sh
python3 -m http.server 8080
# открыть http://localhost:8080
```

Дев-сборки нет — это ванильные ES-модули. Правь и обновляй страницу.

## Структура

```
index.html                 разметка одного экрана (переключатель Radio/TV)
css/app.css                темы, металл/VFD, экран 16:9, вёрстка
js/app.js                  логика, режимы Radio/TV, связка модулей
js/store.js                состояние + localStorage (радио и ТВ)
js/player.js               <video>, HLS/hls.js, Rutube live/VOD, Media Session
js/radio.js                каталог radio-browser + радио-плейлисты (AI/NFS/GTA)
js/tv.js                   встроенные ТВ-плейлисты
js/net.js                  загрузка m3u/HLS через CORS-прокси
js/metadata.js             Icecast/SHOUTcast «сейчас играет» (радио)
js/noise.js                шумы радио при буферизации (Web Audio)
js/m3u.js                  парсер m3u/m3u8/pls (+ quality/note/логотипы)
js/ui.js                   рендер списка/табов/экрана/шитов
playlists/*.m3u            встроенные плейлисты (радио и ТВ)
sample/*.mp3               сэмплы шумов для буферизации
vendor/hls.min.js          hls.js (Apache-2.0) для HLS в Chrome/Firefox
worker/                    CORS-прокси для Cloudflare Workers
sw.js, manifest.webmanifest, icons/
tools/make-icons.mjs       генератор иконок (node tools/make-icons.mjs)
```

## Заметки

- Автозапуск звука в браузерах запрещён без действия пользователя — воспроизведение
  всегда начинается с тапа.
- Потоки требуют интернета; офлайн кэшируется только интерфейс и встроенные m3u.
- **ТВ (HLS)** в Chrome/Firefox идёт через `vendor/hls.min.js`, в Safari/iOS — нативно.
- **Rutube** может требовать VPN вне РФ; CORS-прокси решает только CORS, не гео-блок.
  В списке прокси первым стоит `corsfix` — он нужен для master-плейлиста Rutube.
- **HTTP-потоки** не откроются на HTTPS-странице (mixed content) — встроенные
  плейлисты содержат только HTTPS.
- Каталог радио работает через публичное API radio-browser.info.
